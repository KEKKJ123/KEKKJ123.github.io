LSPatch 免 Root 安装模块

本文最后更新于 2026-09-25T15:07:00+08:00

受不了部分软件广告满天飞？

苦于不能 Root 无法安装 LSPosed？

现在我们有免 Root 的 LSPatch！

本教程将以 QQ 为例，演示安装模块的方法！

注意：QQ 有风控机制，在尝试前请自行评估，数据无价！

零、安装前须知

  • 只有 .apk 格式的模块可以被集成进目标软件。
  • 无论是哪种修补模式，安装包都与原先的签名不同，故必须卸载原先的软件。
  • 由于必须卸载后安装，请注意备份数据！
  • HarmonyOS NEXT 和 iOS 系统无法运行 .apk，故不兼容，不在此篇讨论范围内。
  • 兼容安卓的鸿蒙版本理论可行，尚未测试。
  • Shizuku 为可选组件，用于安装 apk。

一、下载与安装

下载并安装 LSPatch、QAuxiliary，准备 QQ 安装包。这里作者选择了 QQ 9.1.50 版本。

打开 LSPatch，点击新建修补，选择要修补的应用，点击右上角的文件图标，选择 QQ 安装包。

若已安装 QQ，则在要修补的应用选择 QQ。

二、修补模式

本地（推荐）：类似 LSPosed 的设置，多个 Xposed 模块可以作用在同一个软件上。

集成：将模块集成至 .apk，可以分发，隐藏效果也相对更好。

本地模式（管理器模式）

  1. 修补模式选择本地。无需修改任何配置。
  2. 进行修补，等待输出文件。
  3. 导出 apk。选择一个能记住的位置。
  4. 选择导出后的文件，安装。注意：部分手机会报毒，放心安装即可。
  5. 安装成功后，重启 LSPatch。
  6. 再次打开 LSPatch，此时可以看到应用栏显示 QQ 的图标。
  7. 选择 QQ，勾选 QAuxiliary，应用修改。
  8. 强制停止 QQ，重新打开后模块才会被加载。

集成模式（嵌入/便携模式）

  1. 修补模式选择集成。无需修改任何配置。
  2. 嵌入模块栏选择 QAuxiliary，添加方式随安装情况而定。
  3. 进行修补，等待输出文件。
  4. 导出 apk。选择一个能记住的位置。
  5. 选择导出后的文件，安装。

验证模块生效

QQ 版本 ≥ 9.1.50 时，QQ 自带设置页里会出现 QAuxiliary 入口。

三、本地模式与集成模式的区别

本地模式（管理器模式） 集成模式（嵌入/便携模式）
模块位置 模块作为普通 App 单独安装（不能卸载） 模块嵌入修补后的软件
依赖管理器（LSPatch） 是（卸载/冻结管理器会导致模块失效） 否
更改模块 LSP 内修改，无需重新修补 必须重新修补和重装
升级模块 直接覆盖安装新版模块，软件无需修改 每次都要重新修补软件
排查问题 有，LSP 的框架日志 无
模块设置入口 模块软件内（因为保留了其本体） 只能在软件内进
应用列表里有无模块包名 有（多一个暴露面） 无（但运行时 hook 仍可能被检测）
分发给别人 否 是

若不打算更新模块，或只安装单模块，并且追求高隐藏效果，建议使用集成模式。

如果经常更新模块，且在一个软件内安装了多个模块，则建议使用本地模式。
